      How it works

      1. Snapshot — every file is hashed (SHA-256) and its entropy measured; only new content is uploaded to S3 (content-addressed, so encrypted rewrites can never overwrite a clean copy).
      2. Detect — the watcher scores 10-second windows of file activity (rewrite rate, entropy jump, odd extensions…) with a trained RandomForest. An alert opens an incident and marks later snapshots suspect.
      3. Explain — the Claude agent searches backup history and recommends a restore point, citing snapshot ids. It cannot restore anything itself.
      4. Restore — you restore the last clean snapshot (dry run first). Every file is SHA-256 verified; encrypted leftovers are quarantined, never deleted.
